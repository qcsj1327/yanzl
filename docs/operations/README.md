# 运维与本地操作文档

本目录记录本地操作台和数据中心的用户流程。

当前主文档：

- `OPERATOR_CONSOLE.md`：本地操作台 1.0 普通用户工作流。
- `DATA_CENTER.md`：数据中心 1.0 单品种历史行情工作流。

## 固定边界

这些文档不能绕过系统契约：

- 不提供实盘运行流程。
- 不提供真实券商登录流程。
- 不提供 CTP / SimNow 接入流程。
- 不提供自动联网或自动同步流程。
- 不提供 schema / Alembic / 数据库结构修改流程。
- 不提供 OMS、Position、Accounting 手动修改流程。

本地操作台只用于：

- 选择品种。
- 检查配置。
- 同步历史行情。
- 检查覆盖率。
- 检查数据质量。
- 在覆盖通过后查看回测入口。
- 在回测完成后查看纸面模拟。
- 在纸面模拟完成后查看券商只读对照。
- 查看普通安全检查。
- 在开发者模式下查看高级诊断。

后续文档更新应保持普通用户语言优先。开发者细节必须放入开发者模式或高级诊断章节。
